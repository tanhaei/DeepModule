# DeepModule v3.0 Replication Package

This directory contains the public release artifacts referenced in the manuscript's Data Availability Statement. The files are organized to make the evaluation protocol, expert-reference evidence, ablation outputs, boundary-analysis evidence, and cross-language generalization summaries inspectable without rerunning the full benchmark.

## Contents

- `source_code_links.csv`: project list, public repository links, language/domain metadata, and size summaries.
- `ground_truth_summary.csv`: expert-reference construction summary and selected module counts.
- `expert_rubric.md`: anonymized expert-evaluation rubric used for reference decompositions.
- `expert_feedback/*.json`: anonymized per-project expert-feedback summaries.
- `benchmark_outputs/comparative_results_mojofm.csv`: MoJoFM comparison reported in Table 4.
- `benchmark_outputs/ablation_results.csv`: component-ablation summary reported in Table 5.
- `benchmark_outputs/cross_language_results.csv`: generalization summary reported in Table 7.
- `benchmark_outputs/per_run_mojofm.csv`: per-run MoJoFM values (10 runs) for DeepModule and the strongest non-DeepModule baseline per project, supporting the RQ1 significance test.
- `benchmark_outputs/statistical_tests.csv`: paired Wilcoxon signed-rank results (Section 4.4) recomputable with `compute_significance.py`.
- `boundary_reports/boundary_analysis_evidence.csv`: qualitative before--after boundary-analysis evidence reported in Table 6.
- `figures_data/*.csv`: data used to generate the filtering, sensitivity, and convergence figures.
- `schemas/output_schema.md`: description of output columns generated by `main.py`.
- `MANIFEST.json`: machine-readable index of the release package.

## Reproduction

The lightweight pipeline can be checked with:

```bash
python generate_dummy_data.py
python main.py --project_dir ./example_project --clusters 3 --epochs 5 --ground_truth ground_truth.csv --no_codebert --output_dir outputs_smoke
python -m pytest -q tests
```

Full publication-scale runs require the public project snapshots listed in `source_code_links.csv`, the expert-reference assignments, and the optional CodeBERT/Tree-sitter dependencies described in the repository README.

## Reference decompositions for cross-language subsets

The six Qualitas Java projects use expert-constructed reference decompositions
(see `expert_rubric.md` and `ground_truth_summary.csv`). The BigCode Java,
Python, and C++ subsets reported in Table 7 do **not** have expert references.
For those subsets, the reference modularization is derived from the original
top-level package or directory structure of each repository, which provides an
approximate but independent ground truth. This difference in reference quality
should be considered when comparing the BigCode subset scores with the
expert-validated Qualitas results, as noted in Section 4.9 of the manuscript.
